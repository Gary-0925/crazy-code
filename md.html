markdown 水印工具

把文字藏进「空格」里，阅读时看不见，复制时原样出现
原始 markdown
水印 markdown
原理：把普通空格替换成 ![隐藏文字](透明图)。
阅读时图片透明，看起来就像普通空格。
全选复制时，隐藏文字会一起被复制走。
自动跳过：代码块、行内代码、LaTeX 公式、链接 URL、图片语法、HTML 标签、Markdown 特殊字符后的空格、换行符前的连续空格。
新增：开启后，会在每个换行符前自动添加水印（如果该位置没有空格）。
乱码让 Ctrl+F 难以一次性删光水印。
